Pair subtle backgrounds with matching status text. Include a label or icon. Keep category and chart colors for their own roles.

Core component rules

  • Desktop buttons: 28px default height, 12px medium text, 8px radius. Sizes xs / sm / lg: 20 / 24 / 32px.
  • Inputs: 34px height, 8px radius, 14px text that becomes 12px at the md breakpoint.
  • Base cards: 10px radius, 16px padding and gap, subtle foreground ring.
  • Use existing iPad variants for touch screens and Lucide icons for controls.
  • Preserve hover, focus, selected, disabled, loading, and invalid states from the kit.

Use in your app

Copy this repository’s foundations.css, fonts.css, and files folder into your project. Load both stylesheets:

<link rel="stylesheet" href="fonts.css">
<link rel="stylesheet" href="foundations.css">

Apply var(--font-sans), var(--surface-0), and var(--text-default) in your CSS. Add .dark to the document root for dark mode.

Keep the files folder alongside fonts.css so Inter loads correctly. The CSS provides variables; apply them in your own styles. Component measurements are visual guidance, and interactive controls need their own behavior.
